# Nature reviewer response and revision package

Use for editor letters, reviewer comments, rebuttals, revision cover letters, redline excerpts, and response packages.

Parse decision, manuscript metadata, deadlines, required files, and comments into stable IDs such as `E.1` and `R1.1`. Classify each as correction, clarification, new analysis, requested experiment, disagreement, scope issue, or author input needed. Build: comment → action → evidence/change → manuscript location → status.

Each response should acknowledge the point, state the action or principled disagreement, give the evidence, and identify the exact revised location. Mark missing facts `AUTHOR_INPUT_NEEDED`. Never invent experiments, citations, line numbers, figures, supplementary items, editor instructions, or completed changes. Keep reviewer assessment separate from author rebuttal.

If an experiment is impossible, explain the methodological reason, provide the strongest available analysis, narrow the claim, and state the residual limitation. If reviewers conflict, answer each and state the coherent resolution. QA every comment, mapping, quote, number, redline, and format requirement; render LaTeX/print packages before delivery and include remaining author inputs.
